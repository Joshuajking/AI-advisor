What You'll Build

Over the next 5 days, you'll build an AI Advisor - a smart chatbot that can answer questions, use your own knowledge base, and take actions. By the end, you'll understand how modern AI applications work under the hood.

Here's what we'll cover:

  • Day 1: Make your first LLM API call
  • Day 2: Master prompting with system prompts
  • Day 3: Build simple RAG (Retrieval-Augmented Generation)
  • Day 4: Create an AI agent with tools
  • Day 5: Understand production concepts and next steps

Prerequisites

You should be comfortable with:

  • JavaScript/TypeScript basics
  • Running commands in a terminal
  • Basic React concepts (helpful but not required)

Setup Instructions

Step 1: Get the Starter Code

Clone or download the starter project:

git clone [REPO_URL]
cd 5-day-ai-course/ai-advisor
npm install

Step 2: Get Your Gemini API Key

We're using Google's Gemini API because it has a generous free tier - perfect for learning.

  1. Go to ai.google.dev
  2. Click "Get API key in Google AI Studio"
  3. Sign in with your Google account
  4. Click "Create API key"
  5. Copy your new API key

Step 3: Configure Your Environment

Create your environment file:

cp .env.example .env.local

Open .env.local and add your API key:

GEMINI_API_KEY=your_api_key_here

Step 4: Verify Setup

Start the development server:

npm run dev

Open http://localhost:3000 in your browser. You should see the AI Advisor chat interface.

How This Course Works

Each day, you'll:

  1. Watch a short video explaining the concept
  2. Add code to your project following step-by-step instructions
  3. Test your changes and see them work

The code you write builds on previous days, so by Day 5 you'll have a fully functional AI advisor system.
