What You'll Build

Over the next 5 days, you'll build an AI advisory board - a chat interface where you can ask questions like "What does Theo think about testing?" or "What's Primeagen's take on Vim?" and get responses grounded in what these creators actually said.

Pretty cool, right?

Here's what we'll cover:

  • Day 5: See a real product demo and what's next

Setup Instructions

Step 1: Get the Starter Code

Clone or download the starter project:

git clone https://github.com/projectshft/ai-advisor.git
cd ai-advisor
git checkout student-starter
npm install

Important: Make sure you're on the student-starter branch, not main. Main has all the solutions and that's no fun. The whole point is to make this your own.

Step 2: Get Your Gemini API Key

We're using Google's Gemini API because it has a generous free tier - perfect for learning.

  1. Go to ai.google.dev
  2. Click "Get API key in Google AI Studio"
  3. Sign in with your Google account
  4. Click "Create API key"
  5. Copy your new API key

Step 3: Configure Your Environment

Create your environment file:

cp .env.example .env.local

Open .env.local and add your API key:

GEMINI_API_KEY=your_api_key_here

Step 4: Verify Setup

Start the development server:

npm run dev

Open http://localhost:3000 in your browser. You should see the AI Advisor chat interface.
