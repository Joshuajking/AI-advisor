What You'll Build

Today you'll give your AI advisor access to a custom knowledge base. It will search for relevant information and use it to answer questions - this is called RAG.

The Limitation of Day 2

Our advisor is helpful, but it only knows what was in its training data (which has a cutoff date). It can't answer questions about:

  • Your specific products or services
  • Recent developments
  • Expert content you've created
  • Internal documentation

How RAG Works

RAG is a simple but powerful pattern:

  1. Retrieve: Search your knowledge base for content relevant to the user's question
  2. Augment: Add that content to the prompt as context
  3. Generate: Let the AI generate a response using both its training AND your content
User Question: "How should I approach prompt engineering?"
     ↓
[Search Knowledge Base]
     ↓
Found: Article about prompt engineering best practices
     ↓
[Build Prompt]
"Using this context: [article content]
Answer the question: How should I approach prompt engineering?"
     ↓
[AI generates response using the context]

Each entry has:

  • id: Unique identifier
  • topic: The main subject
  • keywords: Terms for matching
  • content: The actual knowledge to inject

Step 2: Build the Retrieval Function

Open lib/rag.ts to see how we search the knowledge base:

// lib/rag.ts
import knowledgeBase from "@/data/knowledge-base.json";

export function searchKnowledgeBase(query: string, maxResults = 3) {
  const queryLower = query.toLowerCase();
  const queryWords = queryLower.split(/\s+/);

  // Score each entry based on keyword matches
  const scored = knowledgeBase.map((entry) => {
    let score = 0;

    // Check topic match
    if (queryLower.includes(entry.topic.toLowerCase())) {
      score += 10;
    }

    // Check keyword matches
    for (const keyword of entry.keywords) {
      if (queryLower.includes(keyword.toLowerCase())) {
        score += 5;
      }
    }

    return { entry, score };
  });

  // Return top matches
  return scored
    .filter((s) => s.score > 0)
    .sort((a, b) => b.score - a.score)
    .slice(0, maxResults)
    .map((s) => s.entry);
}

This is keyword-based retrieval - simple but effective for learning. Production systems use embeddings and vector databases (more on that in Day 5).

Step 3: Inject Context into Prompts

Look at the RAG prompt in lib/prompts.ts:

export const RAG_SYSTEM_PROMPT = `You are an expert AI advisor with access to a knowledge base.

When answering questions:
1. Use the provided context from the knowledge base when relevant
2. Clearly indicate when you're drawing from the knowledge base
3. Combine knowledge base insights with your general expertise
4. If the knowledge base doesn't have relevant info, rely on your training

Context from knowledge base will be provided in [CONTEXT] tags.`;

And the helper function:

export function formatContextPrompt(context: string[], query: string): string {
  const contextBlock = context.length > 0
    ? `[CONTEXT]\n${context.join("\n\n")}\n[/CONTEXT]\n\n`
    : "";

  return `${RAG_SYSTEM_PROMPT}\n\n${contextBlock}User question: ${query}`;
}

Step 4: Wire It Up in the API Route

Open app/api/rag/route.ts to see the full flow:

export async function POST(request: NextRequest) {
  const { message } = await request.json();

  // Step 1: Search the knowledge base
  const relevantEntries = searchKnowledgeBase(message);
  const context = formatRetrievedContext(relevantEntries);

  // Step 2: Build the prompt with context
  const promptWithContext = formatContextPrompt(context, message);

  // Step 3: Generate response with context
  const chat = model.startChat({
    history: [
      { role: "user", parts: [{ text: promptWithContext }] },
      { role: "model", parts: [{ text: "I'll use the knowledge base..." }] },
    ],
  });

  const result = await chat.sendMessage(message);
  return NextResponse.json({ response: result.response.text() });
}

Key Takeaways

  • RAG = Retrieve relevant content + Augment the prompt + Generate a response
  • Your knowledge base can contain any text content
  • Keyword matching is simple but works for learning
  • The AI combines your content with its general knowledge

Limitations to Know

Our simple keyword search has limitations:

  • Only finds exact keyword matches
  • "How do I prompt better?" might miss "prompt engineering"
  • Can't understand meaning, just matches words

Production systems solve this with embeddings - we'll discuss this on Day 5.

Challenge: Extend What You Built

RAG is the most common AI pattern in production. Push yourself:

  • Add your own experts: Pick 2-3 people whose opinions you care about. Add their content to the knowledge base. Could be tech people, business folks, fitness gurus - whatever you're into.
  • Improve the matching: Our keyword matching is naive. Can you add fuzzy matching? Synonyms? What if "testing" also matched "TDD" and "unit tests"?
  • Show your sources: Modify the response to include which knowledge base entries were used. Users love knowing where info comes from.

This is the stuff companies actually pay for. Make it your own.
